# _hospital_demand_forecasting_
This project focuses on predicting hospital demand for the next 13 weeks using historical healthcare data from four hospitals. It analyzes weekly records of OPD visits, patient admissions, lab tests, and billing to identify trends, seasonal patterns, and changes in patient demand.

The project uses time-series forecasting techniques and machine learning models to estimate future hospital demand. It also compares different models to find the most accurate predictions and presents the results through forecast charts and planning tables.

The main goal is to help hospitals plan their beds, staff, and patient follow-ups more effectively, especially during seasonal disease outbreaks like dengue. 

Technologies and Tools: Python, Pandas, NumPy, Matplotlib, Seaborn, Statsmodels, Prophet, and Scikit-learn.
